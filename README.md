你好！这里住着一只对世界保持好奇的快乐小狗。

- ♋ **属性**：巨蟹座 / 水象，脑内偶尔涨潮

- 🧳 **旅游**：定期把自己从工位打包带走，去别的城市。地图要展开，世界要亲自闻一闻！
- 🍅 **红果**：再看一集，就一集。……谁把下一集点开的？哦，是我的爪。
- 🎤 **随时高歌**：随机时间，随机地点，随机掉落个人演唱会。前奏可以没有，感情必须到位。
- 🎢 **新奇体验**：没试过？让我试试！好奇心负责报名，小狗本人负责到场。
- 🎀 **仪式感**：节日认真过，快乐认真存。普通的一天，也可以郑重其事地庆祝一下。
